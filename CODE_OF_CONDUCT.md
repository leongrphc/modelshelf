# Community code of conduct

ModelShelf welcomes contributors of all backgrounds and experience levels. Be respectful, patient and constructive.
Critique ideas and code, not people. Harassment, discrimination, threats, sexualized attention and publication of
private information are not acceptable.

Maintainers may edit or remove harmful contributions and restrict participation to protect the community.
Enforcement should be proportionate and explain the behavior requiring a change.

Report concerns privately to repository maintainers using the contact method listed on their GitHub profiles.
Do not post personal information in public issues. A dedicated community contact must be set before public launch.
