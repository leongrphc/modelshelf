# Reporting vulnerabilities

Please do not disclose exploitable vulnerabilities or access tokens in public issues.
After this repository is published, use GitHub's **Security → Report a vulnerability** if private reporting is enabled.
Otherwise contact a maintainer privately through the contact method listed on their GitHub profile.
No dedicated security email is claimed for this unpublished project.

Include the affected version, operating system, reproduction steps using disposable files,
expected security boundary and observed impact. Avoid sharing private model data or credentials.

Only the latest development version is currently maintained. There is no stable release or response-time guarantee.
Maintainers must enable private vulnerability reporting and establish a security contact before public launch.
See [security design](docs/security.md).
